# PyBot - Simple Python Chatbot

## Description

PyBot is a simple, rule-based chatbot developed using Python. It responds to user messages, tells jokes, displays the current date and time, and provides basic information about Python.

## Features

* Responds to greetings
* Introduces itself as PyBot
* Displays the current time
* Displays the current date
* Tells programming jokes
* Provides basic Python information
* Interactive command-line conversation

## Technologies Used

* Python 3
* Random module
* Datetime module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python simple_ai_chatbot.py
   ```

## Sample Output

```text
WELCOME TO PYBOT 

You: hello
PyBot: Hello! How can I help you?

You: your name
PyBot: I am PyBot, your Python chatbot!

You: bye
PyBot: Goodbye! Keep learning Python. See you again!
```

## Learning Objectives

* Python functions
* Conditional statements
* Loops and user input
* String handling
* Python standard libraries

## Limitations

PyBot uses predefined rules to generate responses. It does not understand arbitrary questions like an advanced AI model.
